## O que ando fazendo

- [Ouvidoria do TCE-MA](https://ouvidoria.apps.tcema.tc.br/): o cidadão registra uma manifestação e acompanha o andamento, e os setores do Tribunal fazem a triagem e a tramitação ali mesmo. Conduzi a reescrita da API (Java 21, Spring Boot 3) e do app (Vue 3, PrimeVue), com login pelo Keycloak.
- SACI (sistema interno): avalia os portais de transparência dos órgãos pelos critérios do PNTP. Uma API em Spring Boot orquestra as varreduras, um worker em Python/Django faz o scraping com Playwright e lê os PDFs, e um painel em Vue mostra como cada órgão está.

## Stack

No back-end uso Java, Spring Boot, Python e Django, quase sempre com PostgreSQL. No front, Vue 3, Nuxt e TypeScript, e React/Next quando o projeto pede. Pra colocar no ar, Docker, Kubernetes e GitLab CI. Autenticação com Keycloak, testes com Playwright e Cypress.
